One root system, many trunks

Your working tree, on every device.

Git keeps the history. Pando carries everything since the last push: modified files, untracked secrets, the index, stashes, between your machines over an encrypted device transport. When the same path changed on both, it asks you instead of picking a winner.

Unreleased · real-machine testing is the release gate

Device first

A machine joins the network once with a single-use code that expires in 15 minutes, then picks which hosted folders it carries. pando revoke removes a device at once.

Never a silent merge

If a path differs on both sides, neither is overwritten. The dashboard offers the network version, this device's, both copies, your editor, or a manual resolution.

Quiet while idle

One daemon per device, at most two repositories transferring at once, reduced CPU and I/O priority, and remote checks spread across each minute.

Try it

Build the binary on each machine and allow TCP 7337 to the first one. There are no packaged releases yet.

# first machine
pando up
pando share ~/Code --name code
pando invite

# every other machine
pando up --to HOST_IP:7337 --code xxxxx-xxxxx
pando join code
pando              # dashboard
